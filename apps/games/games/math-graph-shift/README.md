## 핵심 명제

좌표평면에 시작 함수 (`y = x²`) 가 그려져 있고, 학생이 a, h, k 슬라이더로 `y = a(x-h)² + k` 의 a, h, k 를 조정한다. 목표 그래프 윤곽이 점선으로 흐리게 표시되어 있어, 학생 곡선이 일치하면 정답. **평행이동·확대·반사를 슬라이더로 익힘.**

> **wow 모먼트**: "h를 +1 했더니 식이 (x-1)²로 바뀌고 그래프도 같이 옆으로 밀려"

## 구현 현황

- [x] SVG 좌표평면 (x ∈ [-5, 5], y ∈ [-3, 9]) — 직접 평가 (mathjs 불필요로 단순화)
- [x] a / h / k +/- 슬라이더 (1 단위 step — 0.5 step 은 V4+ 검토)
- [x] 학생 곡선 (jade) + 목표 곡선 (점선) 동시 표시
- [x] 정답 시 점선 사라지고 학생 곡선만 jade
- [x] 현재 식 실시간 텍스트 표시 (`y = a(x - h)² + k` 형태로 부호 처리)
- [x] 5장 카드: 평행이동x/평행이동y/평행이동xy/확대/반사+이동
- [x] FSRS 통합 (정답 계수 정확 일치, wrongCount rating 분기)

## V4+ 확장 검토

- 드래그 인터랙션 (현재는 슬라이더 — 모바일 정확도 트레이드오프)
- 0.5 단위 snap (소수 정답 카드 추가 시)
- 일반 함수 (이차함수 외 — 1차, 절댓값, 삼각함수 등)
- 함수식 동치 비교 (factorization arePolynomialsEqual 패턴 차용)

## 콘텐츠 후보 (V3 작업 시 5장 우선)

1. **평행이동 x (난이도 1)**: `y = x^2` → `y = (x - 2)^2`
2. **평행이동 y (난이도 2)**: `y = x^2` → `y = x^2 + 3`
3. **평행이동 x+y (난이도 3)**: `y = x^2` → `y = (x - 2)^2 + 3`
4. **확대 (난이도 4)**: `y = x^2` → `y = 2x^2`
5. **반사 + 평행이동 (난이도 5)**: `y = x^2` → `y = -(x - 1)^2 + 4`

## 주의

- 드래그 정확도 — 모바일 터치에서 1픽셀 단위 정밀도 X. snap 으로 1단위(또는 0.5)로 보정
- 외재 보상 (이동 횟수 점수 등) 자제. "그래프와 식이 같이 움직인다"가 보상
- mathjs 로 함수식 평가 시 도메인 제한 (분모 0, 음수 제곱근 등) 고려
- factorization 과 같은 manipulation 결 — 시각 차별 (블록 vs 그래프) 충분
