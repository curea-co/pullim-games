# 한국사 연표 정렬 (history-timeline)

- **gameId**: `history-timeline`
- **과목 · 단원**: 사회 / 근대사
- **메커닉**: sorting (정렬)
- **retrieval 깊이**: medium (중간, 인과 출력형)
- **세션 길이**: 약 2분
- **상태**: `available`

## 시작하기

1. **이 디렉토리만 작업하세요.** `apps/games/lib/core/` 변경이 필요하면 별도 PR.
2. `bun run dev` → `http://localhost:3033/games/history-timeline` 에서 확인.
3. 테스트: `bun run test -- games/history-timeline/`

## 핵심 명제

사건 카드 5개가 흩어져 있고, 학생이 시간 순으로 슬롯에 배치한다. 정렬 자체가 인과 retrieval. 단순 암기가 아니라 사건의 선후관계를 손으로 익힘.

> **wow 모먼트**: "시간순으로 놓고 보니까 이 사건이 저 사건 때문에 일어났네"

## 구현 현황

- [x] 시대 라벨 + 5개 사건 카드 그리드 (click-to-fill)
- [x] deterministic shuffle (테스트 안정성)
- [x] 5장 카드: 개항기/대한제국/1910년대/1920년대/광복정부수립
- [x] FSRS 통합 (`@/lib/core` barrel)
- [x] 정답 판정 — orderedIndices === [0..n-1] 비교 (같은 연도는 콘텐츠 작성자가 인과 순으로 입력)
- [ ] V3+ 인과 연결선 SVG 애니메이션 (현재는 정답 시 jade glow + 연도 표시로 단순화)

## 콘텐츠 후보 (V2 작업 시 5장 우선)

1. **개항기 (1876~1894)**: 강화도조약 → 임오군란 → 갑신정변 → 동학농민운동 → 갑오개혁
2. **대한제국 ~ 국권피탈 (1897~1910)**: 대한제국 선포 → 을사늑약 → 헤이그 특사 → 정미의병 → 한일병합
3. **1910년대 무단통치**: 한일병합 → 토지조사사업 → 105인 사건 → 3·1 운동 → 대한민국 임시정부
4. **1920년대 문화통치**: 산미증식계획 → 6·10 만세운동 → 광주학생항일운동 → 신간회 결성 → 윤봉길 의거
5. **광복 ~ 정부수립 (1945~1948)**: 광복 → 모스크바 3상회의 → 미소공동위원회 → 5·10 총선거 → 대한민국 정부수립

## 주의

- 외재 보상 메커닉(스트릭 압박, 점수 비교 등) **절대 X**
- "인과 연결선"은 정답 시 시각 보상이지 자극용 폭죽 아님 — 부드럽게 그어지듯 (proc/spec/08 §8.6)
- 한국사 인물·연도 암기 게임이 되지 않도록 주의 — **선후관계와 인과**가 핵심
