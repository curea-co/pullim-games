# 영어 빈칸 추론 (english-blank)

- **gameId**: `english-blank`
- **과목 · 단원**: 영어 / 수능 빈칸
- **메커닉**: multiple-choice (객관식)
- **retrieval 깊이**: deep (깊음, 추론형)
- **세션 길이**: 약 3분
- **상태**: `available`

## 시작하기

1. **이 디렉토리만 작업하세요.** `apps/games/lib/core/` 변경이 필요하면 별도 PR.
2. `bun run dev` → `http://localhost:3004/games/english-blank` 에서 확인.
3. 테스트: `bun run test -- games/english-blank/`

## 핵심 명제

수능 빈칸 추론 형식 — 짧은 영어 본문에 `___` 자리, 4지선다. 정답 시 본문 빈칸에 정답 단어가 jade 로 삽입. **추론·맥락 retrieval** — 단순 어휘 기억을 넘어선 깊이.

> **wow 모먼트**: "정답이 빈칸에 박히니까 글이 한 흐름으로 이어져"

## 구현 현황

- [x] 본문 + ___ 토큰 + 4지선다 (math-quick-quiz 패턴 차용)
- [x] 정답 시 본문 빈칸에 정답 단어 jade 삽입
- [x] 오답 시 본문 shake + 정답 보기 jade 강조 + 한국어 rationale 표시
- [x] 5장 카드: 자체 작성 본문 (저작권 회피, 어휘/대비/함의/추론)
- [x] FSRS 통합 (정답=good, 오답=again — 객관식 인식형)

## V4+ 확장 검토

- 본문 흐름 시각화 (SVG path animation, 단락 keyword 간 곡선) — 현재는 jade 삽입으로 단순화
- 시간 측정 정보 (평균 풀이 시간 표시, 압박 X)
- 같은 본문을 다른 게임 (어순/어휘) 에서 재출현하는 단일 백본 검증

## 콘텐츠 후보 (V3 작업 시 5장 우선)

V3 작업 시 EBS 수능특강·자체 제작 본문 활용. 외부 저작권물 직접 인용 금지, 자체 paraphrase.

- 1장 — 1단락 80~120 단어, 빈칸 1개, 보기 4개
- 난이도 1~5 — 어휘 난이도가 아니라 추론 단계 깊이
- 주제 다양화 — 사회, 과학, 인문 균형

## 주의

- 수능 빈칸은 단순 객관식 같지만 retrieval 깊이는 **deep** — 본문 전체 맥락 추론 필요
- 외부 본문 직접 인용 금지 (저작권). 자체 작성 또는 EBS 학습용 변형
- 외재 보상 (정답률 비교, 등급 추정) 자제. V3 시점에 학습 데이터 충분하면 "내 약점 단원" 표시 정도는 OK
- 흐름 시각화는 한 번만 (다음 카드로 넘어가면 사라짐) — 화려함 X
