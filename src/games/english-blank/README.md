# 영어 빈칸 추론 (english-blank)

- **gameId**: `english-blank`
- **과목 · 단원**: 영어 / 수능 빈칸
- **메커닉**: multiple-choice (객관식)
- **retrieval 깊이**: deep (깊음, 추론형)
- **세션 길이**: 약 3분
- **상태**: `coming-soon` (V3 라인업)

## 핵심 명제

수능 빈칸 추론 형식 — 짧은 영어 본문에 `___` 자리, 4지선다. 학생이 정답을 고르면 글의 흐름이 강물처럼 시각화 (단락 사이를 흐름 곡선으로 잇는 애니메이션). **추론·맥락 retrieval** — 단순 어휘 기억을 넘어선 깊이.

> **wow 모먼트**: "정답이 들어가니까 단락이 한 흐름으로 이어지는 게 보여 — 글이 살아 움직여"

## V3 본격 구현 시 작업 범위

- [ ] 본문 + 빈칸 토큰 + 보기 UI
- [ ] 정답 시 본문 흐름 시각화 (SVG path 애니메이션, 단락 keyword 간 곡선)
- [ ] 오답 시 rationale 표시 (왜 그게 답이 아닌지 한 줄 해설)
- [ ] 5장 카드 sample (아래 §콘텐츠 후보 참조)
- [ ] FSRS 통합 — 같은 본문을 다른 게임 (어순 / 어휘) 에서 재출현
- [ ] 시간 측정 (선택) — 평균 풀이 시간 표시 (압박 X, 정보용)

## 콘텐츠 후보 (V3 작업 시 5장 우선)

V3 작업 시 EBS 수능특강·자체 제작 본문 활용. 외부 저작권물 직접 인용 금지, 자체 paraphrase.

- 1장 — 1단락 80~120 단어, 빈칸 1개, 보기 4개
- 난이도 1~5 — 어휘 난이도가 아니라 추론 단계 깊이
- 주제 다양화 — 사회, 과학, 인문 균형

## 주의

- 수능 빈칸은 단순 객관식 같지만 retrieval 깊이는 **deep** — 본문 전체 맥락 추론 필요
- 외부 본문 직접 인용 금지 (저작권). 자체 작성 또는 EBS 학습용 변형
- 외재 보상 (정답률 비교, 등급 추정) 자제. V3 시점에 학습 데이터 충분하면 "내 약점 단원" 표시 정도는 OK
- 흐름 시각화는 한 번만 (다음 카드로 넘어가면 사라짐) — 화려함 X
