- **gameId**: `physics-vector`
- **과목 · 단원**: 과학 / 물리I (벡터, 힘의 합성)
- **메커닉**: manipulation (조작)
- **retrieval 깊이**: deep (깊음, 생성형)
- **세션 길이**: 약 3분
- **상태**: `available`

## 시작하기

1. **이 디렉토리만 작업하세요.** `src/lib/core/` 변경이 필요하면 별도 PR.
2. `npm run dev` → `http://localhost:3000/games/physics-vector` 에서 확인.
3. 테스트: `npm test -- src/games/physics-vector/`

## 핵심 명제

좌표평면에 두 입력 벡터가 그려져 있고, 학생이 합벡터의 (rx, ry) 성분을 +/- 슬라이더로 조정한다. 평행사변형 보조선이 학생 합벡터 끝점을 기준으로 자동 표시. **벡터 합성을 슬라이더로 손에 잡힘** — 공식 외우는 게 아니라 성분이 모이는 걸 시각으로 학습.

> **wow 모먼트**: "rx와 ry를 맞췄더니 평행사변형 대각선이 합벡터로 닫히네"

## 구현 현황

- [x] SVG 좌표평면 (x ∈ [-5, 6], y ∈ [-3, 5]) + 격자 + 축
- [x] 입력 벡터 회색 화살표 + label (F1, F2 등)
- [x] 학생 합벡터 +/- 슬라이더 (rx, ry 정수 step)
- [x] 평행사변형 보조선 자동 (학생 합벡터 끝점 기준 점선)
- [x] 정답 윤곽 점선 → 일치 시 학생 화살표만 jade
- [x] arrow marker SVG defs (input/student/correct 3종)
- [x] 5장 카드: 직각/평행/반대/임의각/음수성분
- [x] FSRS 통합 (wrongCount rating 분기)

## V4+ 확장 검토

- 드래그 인터랙션 (현재는 슬라이더)
- 분해 (역방향) — 합벡터 → 두 성분
- 단위 표기 (현재는 성분만, "5N" 같은 SI 단위)
- 3 벡터 합성 (현재는 schema 가 max(3) 지원하지만 V3 1차는 2 벡터만)

## 콘텐츠 후보 (V3 작업 시 5장 우선)

1. **직각 합성 (난이도 1)**: F1 = (3, 0), F2 = (0, 4) → R = (3, 4), |R| = 5
2. **평행 합성 (난이도 2)**: F1 = (2, 0), F2 = (3, 0) → R = (5, 0)
3. **반대 합성 (난이도 3)**: F1 = (5, 0), F2 = (-2, 0) → R = (3, 0)
4. **임의각 합성 (난이도 4)**: F1 = (3, 0), F2 = (2, 2) → R = (5, 2)
5. **3 벡터 합성 (난이도 5)**: 세 힘이 한 점에 작용, 평형 조건 검증
