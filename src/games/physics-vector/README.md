# 물리 벡터 합성 (physics-vector)

- **gameId**: `physics-vector`
- **과목 · 단원**: 과학 / 물리I (벡터, 힘의 합성)
- **메커닉**: manipulation (조작)
- **retrieval 깊이**: deep (깊음, 생성형)
- **세션 길이**: 약 3분
- **상태**: `coming-soon` (V3 라인업)

## 핵심 명제

좌표평면에 두 벡터(화살표)가 있고, 학생이 두 화살표를 잡고 끌면 평행사변형 보조선이 자동으로 그어지면서 합벡터가 도출된다. **벡터 합성을 손으로 익힘** — 공식 외워서 풀던 것을 시각·운동 감각으로 연결.

> **wow 모먼트**: "두 화살표를 양 끝에 놨더니 평행사변형이 그려지면서 대각선이 합벡터가 되네 — 이게 평행사변형 법칙이구나"

## 콘텐츠 후보 (V3 작업 시 5장 우선)

1. **직각 합성 (난이도 1)**: F1 = (3, 0), F2 = (0, 4) → R = (3, 4), |R| = 5
2. **평행 합성 (난이도 2)**: F1 = (2, 0), F2 = (3, 0) → R = (5, 0)
3. **반대 합성 (난이도 3)**: F1 = (5, 0), F2 = (-2, 0) → R = (3, 0)
4. **임의각 합성 (난이도 4)**: F1 = (3, 0), F2 = (2, 2) → R = (5, 2)
5. **3 벡터 합성 (난이도 5)**: 세 힘이 한 점에 작용, 평형 조건 검증
