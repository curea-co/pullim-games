# 함수 그래프 변형 (math-graph-shift)

- **gameId**: `math-graph-shift`
- **과목 · 단원**: 수학 / 함수 (이차함수, 일반 변형)
- **메커닉**: manipulation (조작)
- **retrieval 깊이**: deep (깊음, 생성형)
- **세션 길이**: 약 3분
- **상태**: `coming-soon` (V3 라인업)

## 핵심 명제

좌표평면에 시작 함수 그래프가 그려져 있고, 학생이 그래프를 손가락으로 끌면 함수식이 실시간으로 변한다. 목표 그래프 윤곽이 흐리게 표시되어 있어 그쪽으로 끌면 정답. **평행이동·확대·반사를 손으로 익힘.**

> **wow 모먼트**: "그래프를 옆으로 밀었더니 식 안의 x가 (x-2)로 바뀌네 — 평행이동의 의미를 손으로 알겠다"

## 콘텐츠 후보 (V3 작업 시 5장 우선)

1. **평행이동 x (난이도 1)**: `y = x^2` → `y = (x - 2)^2`
2. **평행이동 y (난이도 2)**: `y = x^2` → `y = x^2 + 3`
3. **평행이동 x+y (난이도 3)**: `y = x^2` → `y = (x - 2)^2 + 3`
4. **확대 (난이도 4)**: `y = x^2` → `y = 2x^2`
5. **반사 + 평행이동 (난이도 5)**: `y = x^2` → `y = -(x - 1)^2 + 4`

## 주의

- 드래그 정확도 — 모바일 터치에서 1픽셀 단위 정밀도 X. snap 으로 1단위(또는 0.5)로 보정
- 외재 보상 (이동 횟수 점수 등) 자제. "그래프와 식이 같이 움직인다"가 보상
- mathjs 로 함수식 평가 시 도메인 제한 (분모 0, 음수 제곱근 등) 고려
- factorization 과 같은 manipulation 결 — 시각 차별 (블록 vs 그래프) 충분
