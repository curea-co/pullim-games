### 작업 범위

- **F1.** GameMeta 확장 (`mechanic`, `retrievalDepth`) (0.5일) — **즉시**
- **F2.** V1.5 게임 2개 stub 추가 (`math-quick-quiz`, `english-order`) (1일) — V1.5 출시 전
- **F3.** 필터 칩 UX (게임 6개+ 시점, 과목 1축) (1.5일) — V2 진입

### 기간

## 10.0b Phase R — 병렬 개발 아키텍처 (Phase 0과 병렬 진행)

게임을 self-contained 모듈로 쪼개서 머지 충돌 없는 병렬 개발이 가능하도록 코드 구조 정비. 상세 기획: [proc/plan/2026-05-08_parallel-game-architecture.md](../plan/2026-05-08_parallel-game-architecture.md)

### 작업 범위

- **R1.** 자동 발견 스크립트 (`scripts/generate-registry.ts`) + manifest 패턴 (1일)
- **R2.** 게임 디렉토리 자급화 (콘텐츠/테스트/copy를 게임 디렉토리 안으로) (1일)
- **R3.** `src/lib/core/` 격리 + barrel import 강제 + ESLint 규칙 (0.5일)
- **R4.** CI path filter + game matrix (git 환경 셋업 후 적용) (0.5일)
- **R5.** 두 번째 게임 스텁으로 머지 충돌 0 검증 (0.5일)

### 검증 기준

- [ ] 새 게임 PR이 `registry.ts` 외 중앙 파일 수정 0
- [ ] 두 worktree에서 두 게임 동시 작업 시 머지 충돌 0
- [ ] 게임 1개 통째 삭제 시 다른 게임 정상 작동
- [ ] `lib/core/` 변경 시 모든 게임 테스트 자동 실행

### 기간

3.5일. Phase 0 사전 게이트와 병렬 진행 가능.

## 10.5 Phase 4 — 신호 수집 + V2 결정 (Week 5-6)

### 작업 범위

- [ ] 한국 고등학생 ≥ 20명에게 링크 전달 (친구·지인 네트워크 + 풀림 플랫폼 채널 검토)
- [ ] 5개 신호 수집:
  1. 재방문 신호 — 첫 세션 5분 후 "한 번 더" 클릭률 ≥ 50%
  2. 명제 신호 — 5분 후 종이로 1문제 정확히 풀이 ≥ 60%
  3. 공유 신호 — 자발적 친구 공유 ≥ 20%
  4. 반박 신호 — "콴다랑 뭐가 달라?" 1초 안에 답변 ≥ 60%
  5. 학습효과 신호 — 7일 후 retrieval 정답률 ≥ 70%
- [ ] 6주 끝에 V2/Pivot/Kill 결정 회의

### 검증 기준 (V2 진입 게이트)

- [ ] 4 신호 중 3개 이상 + 학습효과 신호 통과 → V2 진입
- [ ] 4 신호 중 2개 또는 학습효과 신호 실패 → Pivot
- [ ] 4 신호 중 1개 이하 → Kill (명제 자체 재검토)

### 기간: 2주 (배포 후)

## 10.6 V2+ 로드맵 (참고용, V1 신호 통과 후 결정)

### V2 후보 작업

- 다음 모드 추가 — 빠른 객관식 (가장 가벼움) 또는 단답 풀이 (retrieval 깊음)
- 카드 풀 확장 — 다항식 인수분해 다음 단원 (이차방정식, 함수 그래프 변형 등)
- Magic link 옵션 — fingerprint 손실 보존
- 정식 다크모드 디자인
- B2B 학교/학원 인콰이어리 페이지
- 풀림 플랫폼 SSO 통합

### V3+ 후보 작업

- 다른 과목 라인업 — 화학 화학식 균형, 한국사 연표 등
- AI 자동 메커닉 생성기 (10x 비전)
- B2B 분석 대시보드 정식 출시
- 외형 멤버십 (Prodigy식)
- PWA / 네이티브 앱 검토

## 10.7 Phase별 리스크와 대응

| Phase | 리스크 | 대응 |
|---|---|---|
| 0 사전 게이트 | 5명 테스터 통과해도 false positive 가능 | 표본 한계 명시, V1 신호 수집 단계는 ≥ 20명으로 확장 |
| 1 백본+메커닉 | 수식 라이브러리 선택 잘못 시 1-2주 손실 | 1주차에 비교 결정 강제, 즉시 변경 가능한 추상화 |
| 2 5문제 시퀀스 | AST equivalent form 누락 시 silent miscompute | property-based test 강제, REGRESSION RULE |
| 3 QA + 배포 | 알파 테스터 시간 확보 어려움 | 1주차에 미리 섭외, 카톡 공유 링크 준비 |
| 4 신호 수집 | 20명 표본도 통계적으로 약함 | 신호 통과 시에도 V2 진입 후 추가 검증, 6개월 deadline 명시 |
