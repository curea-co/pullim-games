## 8.2 Typography

### 폰트 (pullim-web 정합 — 3 role)

| role | 폰트 | 용도 |
|---|---|---|
| **본문(kr)** | **Pretendard Variable** (fallback: Pretendard, Spoqa Han Sans Neo) | 한글 본문·UI 기본. `font-sans` |
| **브랜드(brand)** | **Bai Jamjuree** (fallback: Pretendard Variable) | 브랜드 헤딩·워드마크. `font-brand` |
| **mono** | **JetBrains Mono** (fallback: ui-monospace) | 라벨·코드·uppercase 캡션. `font-mono` |

- 본문/브랜드/mono 3종만 사용. `system-ui`·`Inter`·`Roboto`·`-apple-system` 를 **1차 폰트로** 쓰지 않는다(fallback 스택 말단은 허용).
- Pretendard: CDN(`globals.css`). Bai Jamjuree·JetBrains Mono: `next/font/google`(`layout.tsx`, CSS var `--font-bai-jamjuree`·`--font-jetbrains-mono`).

### 스케일

| 토큰 | 크기 | weight | 용도 |
|---|---|---|---|
| `--font-display` | 28-36px | 600 | 다항식 (`tabular-nums`) |
| `--font-body` | 16-18px | 500 | 인스트럭션 캡션 |
| `--font-label` | 14px | 500 | 진행도 (`tabular-nums`) |
| `--font-helper` | 12-14px | 400 | 보조 텍스트 |

`tabular-nums`는 진행도(`3 / 5`)와 다항식 숫자 안정 정렬을 위해 강제.

## 8.5 Shadow

| 상태 | Shadow |
|---|---|
| 블록 resting | none (hairline border만) |
| 블록 dragging | `0 8px 24px rgba(0,0,0,0.12)` |

| 정답 glow | `0 0 24px rgba(0,212,161,0.4)` |

## 8.6 Motion

### Easing

- **Spring**: `stiffness: 280, damping: 24, mass: 1` (Framer Motion 또는 동등 구현)
- **Linear (reduced motion)**: 100ms

### Duration

| 상태 변환 | Duration | Easing |
|---|---|---|
| 블록 transform (정답) | 220ms | spring |
| 블록 spring back (오답) | 150ms | spring |
| 정답 glow fade | 180ms | ease-out |
| Ambient float (idle) | 4000ms cycle | ease-in-out |
| Drop zone 윤곽 변화 | 120ms | ease-out |

### `prefers-reduced-motion: reduce`

- spring → 100ms linear
- ambient float → 정지 (블록 위치 고정)
- glow → 즉시 표시/즉시 제거 (페이드 X)

## 8.7 Layout Grid

- **모바일 (375-430px)**: 단일 컬럼, 화면 폭 - 48px (24px padding 양쪽)
- **태블릿 (768-1024px)**: 최대 폭 480px, 가운데 정렬
- **데스크톱 (1024+)**: 480px 고정 폭, 미세 키보드 힌트 ("터치하거나 클릭")

V1은 모바일 우선. 데스크톱은 모바일 레이아웃 그대로 480px 박스에 표시.

## 8.8 Block Tokenization (다항식 블록 단위)

**Term 단위 = 1 블록.**

예: `2x² + 7x + 3` → 블록 3개 (`2x²`, `7x`, `3`).

공통인수 추출 시 `x`가 새 블록으로 떠나옴 (블록 4개로 변형).

이는 인수분해의 정확한 학습 단위이며, hit area도 적절(약 100-120px 폭)하게 잡힌다.

## 8.9 AI Slop 차단 체크리스트

다음 패턴은 **명시적 금지**. PR 단계에 시각 리뷰로 차단:

- [ ] Purple/violet/indigo 그라데이션 배경
- [ ] 3-column feature grid (해당 없음 — 게임 화면)
- [ ] 컬러 서클 안 아이콘 (메뉴 아이콘은 hairline only)
- [ ] 16px+ bubbly border-radius (블록은 4px)
- [ ] 데코 blob / wave divider (배경은 단색 또는 미세 그리드만)
- [ ] 이모지 디자인 요소 (🎉, ✨, 🚀 X)
- [ ] 컬러 left-border on cards
- [ ] Generic hero copy ("Welcome to...", "Unlock the power of...")
- [ ] Cookie-cutter section rhythm (V1은 단일 페이지라 해당 없음)
- [ ] system-ui / Inter / Roboto / Arial / -apple-system 강제 사용

## 8.10 a11y 토큰

- 최소 터치 영역: `44px × 44px`
- 최소 색 대비: `4.5:1` (AA, 본문)
- 최소 색 대비 강조: `3:1` (AA, 큰 텍스트 18px+)

## 8.12 필터 칩 (V2부터 활성)

상세: [proc/plan/2026-05-08_game-lineup-and-filtering.md](../plan/2026-05-08_game-lineup-and-filtering.md) §7

| 상태 | 배경 | 보더 | 글자 |
|---|---|---|---|
| 비선택 (기본) | `bg-bg-block` | `border-border-hairline` | `text-type-secondary` |
| 선택 | `bg-accent-positive/10` | `border-type-primary` | `text-type-primary` (font-medium) |
| 호버 (비선택) | `bg-bg-primary` | `border-type-secondary/40` | `text-type-primary` |

**핵심 원칙:**
- jade는 배경 tint(10% opacity)로만 — **글자엔 절대 사용 X** (대비 미달, SPEC §8.1)
- 글자는 항상 `type-primary` 또는 `type-secondary`
- 선택 상태는 글자 weight(`500 → medium`)와 보더 강도로 구분, 색이 아닌 무게로 표현
- 칩 자체 라디우스 `rounded-button` (6px). bubble pill 16px+ 금지
- 가로 스크롤: `overflow-x-auto scrollbar-none`. 스크롤바 X.
- 터치 영역: `px-4 py-2` 최소 (44×44 만족)

**다중 선택 X (V2까지):** 단일 선택만. V3에서 재검토.
