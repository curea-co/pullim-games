# 04. 사용자 경험 설계

## 4.1 정보 위계 (게임 화면 5영역)

```
┌─────────────────────────────────────┐
│ 3 / 5                       ≡       │  ← 상단 (10%)
├─────────────────────────────────────┤
│ 공통인수를 찾아 끌어내세요          │  ← 캡션 (5%)
├─────────────────────────────────────┤
│                                     │
│         ┌────────────────┐          │
│         │ 2x²  7x  3     │          │  ← 메인 영역
│         └────────────────┘          │     (60%)
│                                     │
│         (블록 드래그 영역)           │
│                                     │
├─────────────────────────────────────┤
│  ┌- - - - - - - - - - -┐            │  ← 드롭 존 (15%)
│  └- - - - - - - - - - -┘            │
├─────────────────────────────────────┤
│              [ 다음 → ]              │  ← 액션 (10%)
└─────────────────────────────────────┘
```

원칙: 화면을 잡았을 때 "다항식이 블록이네" → "공통인수를 찾으래" → "여기로 끌어다 놓으래" 의 3초 흐름이 자명해야 한다 (Krug "Don't make me think").

## 4.2 사용자 시나리오

### S1. 첫 진입 시나리오 (친구 카톡 링크)

1. 친구가 "이거 봐봐" 카톡 메시지로 `games.pullim.ai` 링크 보냄
2. 카톡 안 OG 카드 = 다항식 블록 큰 시각 + "5분, 인수분해 풀러 가기" CTA
3. 탭하면 모바일 브라우저 → 랜딩 페이지 LCP < 2초
4. "시작" 버튼 탭 → /play 진입, 첫 카드 표시 (FSRS 우선순위 큐 비어있으니 가장 쉬운 카드)
5. 다항식 블록을 탭/드래그 → 공통인수 끌어냄 → 식 변형 → "오 풀었네" 모먼트
6. "다음 →" 활성, 다음 카드로
7. 5문제 완료 → 차분한 요약 → "한 번 더" 또는 "오늘은 끝"

### S2. 재방문 시나리오 (FSRS 우선순위)

1. 어제 5문제 풀었던 동일 fingerprint 사용자
2. /play 진입 시 FSRS 큐가 어제 풀이 데이터 기반 우선순위 카드 5장 출제
3. 어제 헷갈렸던 카드 우선 (R 낮은 카드)
4. 1주 후 재방문 시 그날 풀었던 카드가 FSRS 알고리즘에 따라 retrieval test로 재출제

### S3. 빈 큐 시나리오

1. 모든 카드가 "오늘 안 풀어도 됨" 상태 (R 충분)
2. /play 진입 시 다항식 자리에 "오늘은 여기까지예요" 차분한 메시지
3. 다음 학습 가능 시간 표시 ("내일 오후에 다시 만나요")
4. 데모 모드 진입 옵션 ("그래도 한 판 더 풀고 싶다면") — FSRS 무관 random 카드

### S4. 에러 시나리오 (네트워크 단절)

1. 풀이 도중 네트워크 끊김
2. 진행 상태는 로컬에 보존
3. 다음 인터랙션 시 "네트워크가 흔들렸어요. 다시 한 번 시도하세요" 토스트
4. 네트워크 복구 시 자동 sync, 사용자에게 별도 알림 X (silent recovery)

## 4.3 Navigation Flow

V2부터 메인페이지 URL에 필터 쿼리 파라미터가 추가됨 (`?subject=math&mechanic=manipulation`). 브라우저 백버튼·공유·새로고침 모두 작동.

```
[카톡/인스타 링크 진입]
       │ (메인 또는 직접 게임 URL)
       ▼
[ / 메인페이지 (게임 picker) ]
       │
       ├─[필터 칩 탭 — V2+]──▶ [ /?subject=math ] (같은 페이지, 필터 적용)
       │   ├─[추가 칩 탭 — V3+]──▶ [ /?subject=math&mechanic=manipulation ]
       │   └─[전체 보기]──▶ [ / ] (필터 초기화)
       │
       ├─[추천 카드 탭 — V2+]──▶ [ /games/[gameId] ]
       │
       ├─[게임 카드 탭]──▶ [ /games/[gameId] ]
       │                          │
       │                          ├─[정답×5]──▶ [완료 화면]
       │                          │                │
       │                          │                ├─[한 번 더]──▶ [/games/[gameId] 재시작]
       │                          │                ├─[다른 게임]──▶ [/ 메인페이지]
       │                          │                └─[오늘은 끝]──▶ [/ 메인페이지]
       │                          │
       │                          ├─[빈 큐]───▶ [빈 큐 메시지]
       │                          │                │
       │                          │                ├─[데모 모드]──▶ [/games/[gameId] 데모]
       │                          │                └─[돌아가기]──▶ [/ 메인페이지]
       │                          │
       │                          └─[≡ 종료]──▶ [/ 메인페이지]
       │
       └─[직접 URL — /games/factorization]──▶ 위와 동일
```

V1 라우팅: `/` (메인) + `/games/[gameId]` (동적). `[gameId]`는 registry에 등록된 모든 게임 자동 처리.

## 4.4 인터랙션 상태 매트릭스

| 카드 fetch | 다항식 블러 + 200ms 진동 | "오늘은 끝" 메시지 | "다시 한 번" 토스트 | 다항식 표시 | — |
| 드래그 | — | — | 블록 spring back 150ms | 1.05 scale + shadow | hit zone 자동 강조 |

| 5문제 시퀀스 | 카드 prefetch | — | 진행 보존 후 sync | "한 번 더"/"오늘은 끝" 동등 비중 | "다음 →" 활성 |
| FSRS 큐 갱신 | (백그라운드) | — | (silent retry) | 다음 카드 결정 | — |

## 4.5 RBAC (V1.x)

**2026-07-04 개정** — 입구 신원 모델(§5.2, 2026-06-01~)과 회원 신원 중앙 위임(SSO, 2026-07-04)에 정합. 구 "V1=비로그인 권한 단일"은 대체됨. 권위는 `spec/05 §5.2`.

| 역할 | 권한 | 신원 |
|---|---|---|
| 게스트 (입구 신원) | 게임 플레이, 자기 진행도 조회(localStorage) | games 독립 — 닉네임+학년(`pullim-games:player`), 서버 전송 0 |
| 회원 | 게임 플레이, 자기 학습 데이터 조회·다기기 동기화(**정책상 목표 — `/api/sync` 클라 연결은 후속 phase, 현재 미제공**) | **pullim-api 중앙 인증(SSO)** — `.pullim.ai` 쿠키 세션, `sub` 식별(내부 저장 키는 `users.id`). 플레이는 entitlement flag 무관 무료 |

- 회원/게스트 모두 게임 플레이 = 무료(games flag 무관). `flags.games`(교사제작)는 별도 — V1 범위 밖.
- V2에서 추가 예정 권한: 학부모(자녀 분석), 교사(반/학생 분석·게임 제작), 관리자(콘텐츠 관리).

## 4.6 첫 30초 모먼트 설계

핵심 와우 모먼트 = "어 이거 풀이 자체가 게임이네?"

| 시간 | 사용자 행동 | 사용자 감정 | 시스템 |
|---|---|---|---|
| 0-2초 | 페이지 로드 | 호기심 | LCP < 2초, 다항식 블록 첫 페인트 |
| 2-5초 | 다항식 블록 보고 캡션 읽음 | "어 이게 끌리네?" | ambient float Y±2px (4초 cycle) |
| 5-15초 | 첫 드래그 시도 | 신기함 | 잡힌 블록 1.05 scale + shadow |
| 15-30초 | 첫 정답 도달 | 자기효능감 | 식 spring morph + jade glow |

핵심 설계 결정: 첫 카드는 가장 쉬운 형태 + ambient hint ("끌어 보세요" 미세 힌트). 튜토리얼 없음.

## 4.7 a11y 명세

- 터치 영역 ≥ 44×44px (블록, 메뉴 모두)
- 키보드 네비게이션: Tab 선택 / Space·Enter 잡기 / 화살표 이동 / Enter 놓기
- 스크린리더: 다항식 `aria-label="다항식 2x 제곱 더하기 7x 더하기 3"` (자연 한국어 발음), 블록 `role="button"` + 상태 announce
- 색 대비 AA (4.5:1) 이상. Accent jade는 background/glow 한정, 글자 사용 금지
- `prefers-reduced-motion: reduce`: spring → 100ms linear, ambient float → 정지
- IME 충돌 방지: 게임 화면 텍스트 입력 0개라 IME 문제 0
