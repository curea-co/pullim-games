# 06. 콘텐츠 데이터셋

## 6.1 V1 카드 풀 (5장 인수분해)

V1 = 고1 공통수학 다항식 인수분해 5문제. 난이도 시드 1~5 점진 상승. 마지막은 "오 진짜 풀었네" 와우 모먼트.

| 카드 로드 실패 | "잠시 다시 만나요. 새로고침해 주세요." |

토스트는 미세하고 조용하게. 빨간 경고 색 X (오답이 아니라 시스템 문제이므로 grey 톤).

## 6.6 인스트럭션 캡션 콘텐츠 (카드별)

| 카드 | 캡션 |
|---|---|
| Card 1 | 공통인수를 찾아 끌어내세요 |
| Card 2 | 더해서 5, 곱해서 6이 되는 두 수를 찾아보세요 |
| Card 3 | 공통인수를 찾아 끌어내세요 |
| Card 4 | 세제곱의 차로 보면 어떨까요? |
| Card 5 | x²을 다른 문자로 두면 어떨까요? |

캡션은 "정답을 알려주는 힌트"가 아니라 "방향을 가리키는 힌트"여야 한다.

## 6.7 콘텐츠 큐레이션 정책

- V1 5장 = 손작업 (콘텐츠 큐레이터 1명, 1주차 작업)
- 매 카드는 페이퍼 프로토타입에서 5명 테스터 피드백 후 난이도 시드 조정 가능
- V1 끝나면 카드 풀 확장 작업 분리 (V2)
- AI 자동 생성은 10x 비전, V1 의존성 없음

## 6.8 input/ 디렉토리

`input/` 비어 있음. V1 콘텐츠는 위 5장 카드 풀이 전부. 추가 참조 자료 필요 시 `input/`에 추가 후 본 문서에 명시 갱신.

## 6.9 V1.5+ 게임 콘텐츠 계획 (참고용)

상세: [proc/plan/2026-05-08_game-lineup-and-filtering.md](../plan/2026-05-08_game-lineup-and-filtering.md) §5

각 게임은 출시 전 5장 카드 큐레이션 작업이 별도 PR로 진행된다. 현재 단계에서는 단원 매핑만 명시:

| 게임 | 과목 | 단원 후보 (5장 큐레이션 기준) |
|---|---|---|
| `math-quick-quiz` (V1.5) | 수학 | 고1 전 단원 — 인수분해·이차방정식·함수 기초 등 30초 단답 5문제 |
| `english-order` (V1.5) | 영어 | 5형식 어순, 형용사·부사 위치, 한국어→영어 어순 변환 |
| `history-timeline` (V2) | 사회 | 한국 근대사 — 강화도조약·갑신정변·동학·갑오개혁·을사조약 등 |
| `english-word-match` (V2) | 영어 | 수능 어휘 빈출 — 영-한 의미 짝 매칭 |
| `chemistry-balance` (V2) | 과학 | 화학I 반응식 균형 — 연소·중화·산화환원 |
| `vocab-typing` (V2) | 국어 | 한자 어휘 — 사자성어, 한자 입력 |
| `math-graph-shift` (V3) | 수학 | 함수 그래프 평행이동·대칭이동 |
| `english-blank` (V3) | 영어 | 수능 빈칸 추론 — 논리 연결사 기반 |
| `physics-vector` (V3) | 과학 | 물리 — 힘 합성, 평행사변형 법칙 |

각 게임의 카드 5장은 출시 전 1주차 페이퍼 프로토타입 단계에서 콘텐츠 큐레이터가 작성.
